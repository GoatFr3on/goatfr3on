# GitHub Profile README Tutorial

Create a GitHub profile like the one shown in the video by using a special repository with the **same name as your GitHub username**.

> **Important:** GitHub profile repositories must use the exact same name as your username.

## 1. Open GitHub

Go to [https://github.com](https://github.com) and sign in to your account.

## 2. Create a new repository

1. Click the **+** button in the top-right corner.
2. Select **New repository**.
3. In the **Repository name** field, enter your exact GitHub username.
   - Example: If your username is `octocat`, the repository must be named `octocat`.
4. GitHub should recognize it as a **profile README repository**.
5. Add a short description if you want.
6. Set the repository to **Public**.
7. Select **Add a README file**.
8. Click **Create repository**.

## 3. Open your README.md

After creating the repository:

1. Open the repository.
2. Open `README.md`.
3. Click the **pencil/Edit** button.
4. Remove the default README content.

## 4. Add the profile README template

Copy the provided README template into your `README.md`.

The template is only a starting point. **Do not copy it unchanged if you want the profile to represent you.**

## 5. Personalize the README

Replace the example information with your own details.

Update things such as:

- Your name
- Short introduction
- Profile picture or GIF
- Tech stack
- Programming languages
- Tools and frameworks
- GitHub statistics
- Social media links
- Portfolio link
- Contact information
- Current interests
- GitHub widgets or badges

### Example

If the template contains:

```text
Hi, I'm YOUR_NAME
```

change it to your own name.

If it contains:

```text
React | TypeScript | Python
```

replace or extend it with the technologies you actually use.

If it contains social links, replace the example URLs with your own profiles.

## 6. Add images and GIFs

If the README template uses images or GIFs:

1. Upload your own assets to the repository, or use reliable image URLs.
2. Replace the example image URL with your own.
3. Keep the image dimensions and layout in mind so the profile remains clean.

## 7. Customize the design

You can modify:

- Headings
- Emojis
- Text
- GIFs
- Icons
- Badges
- Tables
- Section order
- Colors supported by the assets/widgets you use

Make the profile match your own style rather than trying to reproduce someone else's profile exactly.

## 8. Preview your README

Before saving your changes, use GitHub's **Preview** option to check:

- Images
- Links
- Spacing
- Headings
- Badges
- GIFs
- Overall layout

Fix anything that looks broken.

## 9. Commit your changes

When everything looks good:

1. Scroll down to the commit section.
2. Add a short commit message.
3. Click **Commit changes**.

Your profile README should now appear on your GitHub profile.

## 10. View your profile

Go to:

```text
https://github.com/YOUR_USERNAME
```

Your customized README should appear on your profile.
